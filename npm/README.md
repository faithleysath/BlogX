# @faithleysath/blogx

This package installs the BlogX CLI from the GitHub Release binaries.

```bash
npm install -g @faithleysath/blogx
blogx --version
```

Supported prebuilt npm platforms:

- Linux x86_64 glibc
- Linux aarch64 glibc
- macOS Intel
- macOS Apple Silicon

Windows and musl/Alpine builds are not part of the current prebuilt release matrix.
